# YJ-Pocket-Desktop v1.2.3 — pre-release

A portable, local-first media desktop for browsing one chosen library of photos, videos, music, and recordings. The English product page is now the repository default; a Chinese edition and bilingual development guides are also available.

This release organizes source and tests by feature, places the editable 30-second promo in `docs/media/`, and removes generated promo audio from the source tree. The current UI still offers filename filtering **within the current Finder folder**. Automatic multi-drive discovery, indexed cross-drive search, and in-app safe organization are planned, not shipped.

Windows asset: `YJ-Pocket-Desktop-1.2.3-win-x64.exe` (101,029,688 bytes)

SHA-256: `65E23F8519DB997624C653BDDC3266AF342DB09F85F31FC45DC09763E7FBED85`

Verification: lint, TypeScript checks, 3 automated tests, promo type check, Windows package build, and package-content comparisons passed. The EXE is **not digitally signed**. Enterprise code-integrity policy prevented launch testing on the build machine, so this is a pre-release; please validate startup and media flows on a Windows machine that permits unsigned apps. macOS/Linux packages are not provided or validated. No personal media is included.

### Run this unsigned Windows preview

Download the EXE only from this official release. Open PowerShell in the download folder, run `Get-FileHash .\YJ-Pocket-Desktop-1.2.3-win-x64.exe -Algorithm SHA256`, and compare it with the SHA-256 above; **do not run it if they differ**. On a personal device that permits unsigned apps, if Windows shows only the SmartScreen “Windows protected your PC” reputation warning, select **More info → Run anyway** only after confirming the source and hash. Open the portable EXE and select your media folder in Settings.

If that option is absent, an administrator or Smart App Control blocks the app, or antivirus reports a threat, stop. Do not disable Windows security features or override organizational policy. Use a permitted device or contact your administrator. This package has not passed a real Windows launch test.
