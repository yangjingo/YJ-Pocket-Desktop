# 原型到实现的对照

本表对照当前项目能力与目标；2026-09-30 加入多盘创意终端的阶段边界。未公开的 Gemini HTML 原型是历史视觉参考，不是已交付功能。

| 领域 | Gemini 原型 | 当前 YJ-Pocket-Desktop | 设计目标 / 接线位置 |
| --- | --- | --- | --- |
| 桌面材质 | 点阵、液态玻璃、橙色设备点 | [skeuomorphic.css](../../app/styles/skeuomorphic.css) 使用固定冷钢蓝灰背景、浅金属窗口、相纸、唱盘、CRT 和实体按键；旧 Three.js 背景已隐藏 | 保持内容面清晰，检查各机件的真实状态与窄屏可读性 |
| 应用入口 | 四个媒体图标、四个 Dock 钉 | [index.html](../../app/index.html) 有四类素材档案与通用文件夹；Dock 保留 Finder 和设置 | 五枚桌面文件夹共用工业铝材风格；通用文件夹打开 Finder，运行点反映窗口状态 |
| 窗口 | 四个可拖动、可缩放的独立媒体窗 | `finder`、`preview`、`settings` 三类窗 | 让四个媒体模式有独立窗口状态；共享窗口壳和拖动/层级逻辑 |
| 照片 | 远程 `picsum.photos` 示例与固定显影遮罩 | [desktop.ts](../../src/client/desktop.ts) 读本地图片、缩略图，在深色看片台预览 | 用真实加载事件驱动看片台和胶片托盘 |
| 录音 | 磁带轮与按钮演示；±15s 只改显示文字 | 录音入口加载现有声音档案 HTML | 用真实 `<audio>` 控制磁带轮、时间、seek 和对话稿跳转 |
| 音乐 | 唱片 CSS 旋转；按钮不播放音频 | 原生 `<audio>` 连接唱片、进度、五枚按键和音量旋钮 | 用真实音频与窄屏视口验收，失败状态需可见 |
| 视频 | 远程示例视频 + CRT 外框 | 原生 `<video>` 播本地视频，失败时支持转换 | 保留真实播放与转换，增加不遮挡控件的 CRT 皮肤 |
| 文件系统 | 无本地目录能力 | [http.ts](../../src/server/http.ts) 提供列表、缩略图、媒体 range 请求 | 文件夹在 Finder 里成为子房间；媒体应用共享该数据源 |
| 媒体检索 | 无本地资源检索 | 当前列表按文件名过滤；顶栏银色搜索图标聚焦 Finder 输入框；录音档案可按名称过滤，服务返回文件修改时间 | [PRD-SEARCH-001](PRD.md)：已授权素材源的索引、跨盘关键词和日期筛选 |
| 多盘来源 | 无本地磁盘发现 | 当前设置只指定一个媒体根目录 `D:\YJ-Media` | [PRD-SOURCE-001](PRD.md)：卷发现、授权范围、稳定身份、插拔盘与离线状态 |
| 安全整理 | 无文件整理 | 2026-09 的一次性目录迁移已完成；应用内尚无通用整理流程 | [PRD-ORGANIZE-001](PRD.md)：预览、冲突检测、确认、核验与可恢复记录 |
| 设置与语言 | 无设置 | [settings.ts](../../src/server/settings.ts)、[i18n/index.ts](../../src/client/i18n/index.ts) 已支持语言/路径/Key | 视觉统一，补齐新增文案及窄屏状态 |
| 启动 | 直接打开静态演示 HTML | 浏览器模式由本地 Node 服务启动；Windows 1.2.3 预发布包位于 `dist/packages/`，此机企业策略阻止其运行验收 | 在可运行的 Windows 设备验证最大化启动与单实例；其他平台各自验收 |
| 性能 | 静态演示，无真实磁盘扫描 | 3D 场景首屏后初始化且静止时停止绘制；媒体类别列表短时复用，刷新强制重扫 | [轻量索引技术方案](search-index-architecture.md)：后台索引代替查询时整盘遍历，监测启动时间、RSS、包和索引大小 |

## 实施约束

- 以现有 TypeScript 前端、Node 服务和本地媒体路径为数据层。视觉升级不修改录音原件、转录缓存和已生成对话稿。
- Gemini 原型的远程演示媒体不进入正式页面；本地缩略图与视频转换继续复用 `.yj-cache`。
- 设备外观应是视图组件，播放状态只有一个来源：实际的 `HTMLMediaElement`；拖动条和时间读数由媒体事件更新。
- 用户资料与 MiniMax Key 不写入规格、日志、HTML 或截图。设置接口只返回是否已配置。
- 根目录保留源码仓库必需文件；参考原型位于 `docs/specs/reference/`，编译产物与本地归档进入忽略的 `dist/`。
