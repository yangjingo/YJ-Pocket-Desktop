# 交互与媒体规格

## 1. 打开桌面

当前 Windows 1.2.3 启动入口是 `YJ-Pocket-Desktop-1.2.3-win-x64.exe`（GitHub 预发布附件；本地构建于 `dist/packages/`）。双击后应直接打开 Electron 桌面窗口，内置服务在本机安全高端口范围选取空闲端口；多次双击聚焦同一窗口。设置与缓存留在系统用户数据目录，品牌改名时复制旧设置。当前设备的企业签名策略阻止未签名 EXE 启动验收；浏览器入口与打包条件见[Electron 分发规格](electron-distribution.md)。

网页本身占满窗口内容区。浏览器模式由 `npm start` 启动，服务运行时可访问 `http://127.0.0.1:8765/`。两种模式都只监听本机回环地址。

## 2. 桌面与窗口

- 桌面有照片、视频、音乐、录音四类素材档案图标及一枚通用文件夹。四类素材沿用原有入口，通用文件夹打开 Finder；设置从 Dock/顶栏进入。
- 点击图标或 Dock 入口打开/聚焦应用；Dock 橙色点表示窗口可见，琥珀色短线表示窗口已最小化。窗口关闭后再点可重新打开。
- 窗口标题栏可拖动；红色关闭并释放预览，黄色最小化并保留浏览/播放/未保存设置状态，绿色在放大与还原之间切换。Dock 点击可恢复最小化的窗口。按钮有中英文动作名称和状态提示；点击窗口升到最前，非当前窗口的控制点变灰。
- `YJ-Pocket-Desktop` 品牌悬停或点击显示当前媒体路径、已用/总量/剩余容量；窄屏可显示 `YJ Pocket` 简写，完整名称保留在无障碍标签与页面标题。右侧保留搜索、设置、日期和时间，日期与时间随语言设置切换。
- `Escape` 关闭顶层临时弹层或预览。媒体播放窗口最小化时，播放状态必须与实际音频/视频一致；如选择停止播放，按钮和动画同步恢复。

## 3. Finder 与子房间

Finder 的根是设置中的本地媒体路径。已有文件夹作为子房间显示在侧栏和文件网格；面包屑可返回任意父层。图片、视频、音频可按类型浏览；当前搜索仅过滤已加载列表，顶栏银色搜索图标只聚焦该输入框。多盘索引、跨子文件夹的日期与关键词检索见[PRD-SEARCH-001](PRD.md)，目前尚未实现。打开文件时保留来源路径和前后项顺序。空文件夹、路径无效、无权限、文件删除各有明确状态，不能显示旧结果。

照片、音乐和视频应用可从同一根路径分别筛选对应媒体。文件名、时长/大小、所在子房间可见；没有数据时呈现空库说明与“打开 Finder/设置路径”操作。

## 4. 媒体窗口

| 窗口 | 输入与展示 | 必须真实生效的动作 |
| --- | --- | --- |
| 照片看片台 | 本地图片、相纸主图、胶片托盘、文件名与来源 | 选片、前后切换、加载/失败状态、查看原文件 |
| 磁带回放 | `D:\YJ-Media\Recordings\IPhone-Voice` 的录音及对应 HTML 对话稿 | 播放/暂停、拖动到时间点、±15s、音量、打开带时间锚点的对话稿；多人标签只在识别可靠时显示 |
| 黑胶唱机 | 本地音频列表、当前曲名、时长、进度 | 播放/暂停、上一首/下一首、seek、音量；转盘随 `<audio>` 状态变化 |
| CRT 视频 | 本地视频、海报帧、时长、进度 | 播放/暂停、seek、音量、全屏；无法直接解码时触发兼容格式转换并反馈进度/结果 |

同一媒体文件只建立一个播放实例。切换曲目、录音或视频时释放旧媒体资源，避免后台重叠播放。浏览器自动播放受限时显示播放按钮等待用户操作。视频的 CRT 扫描线是 `pointer-events: none`，不能盖住媒体控制。

录音对话稿保持简洁 HTML：说话人段落、可跳转时间戳、观点摘要与会议纪要。标记“说话人未区分”的文件不能被视觉样式暗示已完成声纹识别。转录批处理独立于桌面启动；用户打开桌面不应触发全量请求。

## 5. 设置

设置包含：简体中文/英文、媒体路径、MiniMax API Key。语言由 `i18next` 管理，涉及菜单、日期、空状态、按钮与错误提示。桌面固定使用冷钢蓝灰背景，承载透明背景的铝制素材档案 SVG。路径修改后刷新 Finder 和媒体列表。Key 输入框不回显已保存内容，只显示“已配置/未配置”；保存与清除都需要明确反馈。

## 6. 响应式与验收

- 在 1440 × 900 桌面视口，顶栏、五个图标、Dock 和打开的媒体窗口完整显示；窗口可以移动且文件能实际播放。
- 在 390 × 844 窄屏视口，顶栏、图标、Dock、设置和媒体控件可用，页面无横向溢出；窗口内容自身滚动。
- 切换中英后，顶栏日期与界面文案同步变化；默认背景下路径和按钮保持可读。
- 再次双击 EXE 时聚焦已有窗口；关闭应用后重新双击可冷启动；断网环境里本地桌面与媒体仍可访问。
- 每个拟物播放动作都能用媒体元素的 `currentTime`、`paused`、`duration` 或实际文件内容验证，不能只改 CSS 或显示数字。
