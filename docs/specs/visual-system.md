# 视觉系统：可操作的 3D 媒体陈列台

版本：2026-09-18。文件窗口沿用未公开的 Gemini HTML 原型框架；首页已改为 Three.js 实时渲染的媒体物件陈列台。具体物件参考[播放器图片](../ui/music-player-reference.md)、[Inspora 两例](../ui/inspora-references.md)、[Smartisan OS 访谈](../ui/smartisan-os.md)和未公开的本地设计手册与 SVG 草图。这些是设计来源，不是可直接复制的资产。

## 视觉命题

屏幕是统一的中性银色金属空间。背景、地面、连续升降桌面、顶栏、标题显示仓、底部媒体 deck 与 Finder 共用拉丝银铝、倒角、黑色内凹面、螺丝和克制的琥珀指示灯；不使用蓝色。照片、视频、音乐、录音和文件各自有不同的 3D 轮廓：相机与相纸、双卷盘摄影机、黑胶唱机、手持录音机、抽屉档案柜。五个展座只承担共同的陈列语法，不能让媒介物件退化为一款通用文件夹的贴图变化。

首页的 Three.js 场景使用真实几何、程序化拉丝纹理、银色金属材质、俯视透视、中性白色光与接触阴影。五件物件和展座立在同一块可升降台板上，三组伸缩支撑随之运动；HTML 金属 deck 的五枚实体按键是同一批入口的键盘与无 WebGL 后备操作面，升降键控制 72–112 cm。旧 Dock 不显示，设置仍留在顶栏。Finder 内部文件夹继续使用本地银灰透明 SVG；早期黑底 PNG 与五枚同形文件夹 SVG 是探索稿，不代表当前首页，也不是 macOS `.icns` 系统图标包。

五件媒介设备同等重要；黑色只用于镜头、显示仓、唱片、网格和其他内凹功能面，不作为大块主题色。用户自己的照片、视频等媒体内容保留原色，周围设备与软件外壳保持银灰。长文件名、转录稿与纪要使用平整高对比阅读面。

## 材质与光源

| 部件 | 材质表达 | 状态 |
| --- | --- | --- |
| 首页展台与窗口 | 银灰背景、银色升降桌、五件独立 3D 媒介物件、浅色金属窗口 | 模型悬停抬起，点击进入对应素材；窗口保持独立层级 |
| Finder 与设置 | 浅灰凹槽、实体按钮 | 焦点、按下、禁用必须可辨认 |
| 相纸与预览台 | 深色看片台、白色相纸边框 | 当前文件高亮，图片加载按真实结果显示 |
| 音乐 | 银色机身、黑胶、磨砂金属旋钮 | 播放时转盘转，音量对应指针角度 |
| 视频与录音 | 银色机身、黑色显示仓/回放面 | 不让纹理遮住媒体控件或对话稿 |

主光源来自左上，所有壳体、按钮和展品沿同一方向生成高光与阴影。琥珀色只标记状态、播放和交互重点。桌面背景固定为银灰材质，不提供壁纸切换；参考图中的棋盘格只是透明底提示，不是壁纸。旧装饰性 Three.js 圆环已被有实际入口功能的 3D 物件取代。

阴影只保留壳体与桌面、按键与底座接触处的短距离暗部。层级主要由边框、倒角、材质明度和内凹结构表达；不要给每个部件叠加大范围的深色光晕。桌面窗口的投影也须保持克制，避免遮住图标与文字。

小字号文字使用足够深的中性灰。上一版对文件元数据、侧栏标题、Dock 标签、功能橙说明和窗口铭牌五处的抽样对比度为 4.61:1–7.34:1；该数据不代表当前银色版的完整无障碍审计。

## 尺寸与排版

- 顶栏约 62px，窄屏约 49px。左侧品牌悬停或点击显示媒体路径与磁盘容量；右侧保留设置和本地化时间。首页不再排列传统应用菜单。
- 首页左上角不再显示星形 Logo 按钮和“让素材各有其形”标题牌；品牌名仍在顶栏，主视觉交给可交互的 3D 媒体物件。中英文共用这一布局，英文画面与字幕单独拍摄、导出。
- 大屏五件物件并列陈列，底部是一整块带五枚可操作金属按键的 deck；窄屏聚焦单件物体，左右露出相邻物件，可扫动切换。设置留在顶栏。
- 旧 Dock 不在首页显示。窗口控制点使用银灰深浅区分关闭、最小化、放大/还原，悬停或聚焦显示语义符号。
- 文件、字幕、纪要使用可读的系统中文字体；计时、容量、路径可用等宽字体。极小的设备铭牌不承担正文信息。
- 390px 宽度下 3D 展台聚焦当前物件，分类入口保持一行；窗口覆盖展台并让内容独立滚动。320px 短屏下设置窗口的保存操作始终可见。
- 701px 以上五件展品并列；Finder 利用顶栏以下的高度，文件区独立滚动。

## 动效与性能

- 首页 3D 展品仅做轻微角度与悬停抬升；音乐播放器中的唱片仍只在音频真实播放时旋转，进度和时间取自 `<audio>` 事件。
- 窗口与按钮主要改变 `transform` 和 `opacity`；避免大面积持续模糊与阴影动画。
- `prefers-reduced-motion` 停止 3D 循环与唱片旋转，保留静态展品、文字、按钮和时间状态。
- 鼠标、触屏与键盘都要能操作音量和进度。焦点环独立于材质高光。
- 无 WebGL、背景不可见或窗口失焦时仍保持完整的 HTML 界面。
