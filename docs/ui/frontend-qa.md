本轮把大范围、重复叠加的阴影收敛为短距离接触阴影；壳体层次改由边框、倒角、明度和内凹面表达。桌面图标、Dock 和媒体设备仍保留物件结构。

该阶段的视觉迭代依据 `design/` 中的手册与 SVG 草图，绘制统一的冷铝壳、内凹面和铜橙刻度。五枚桌面图标、六枚 Dock 图标与 Finder 侧栏当时复用同一组内联 SVG；旧的软白卡片和无用图标样式已移除。五处小字号文字的抽样对比度为 4.61:1–7.34:1；这一数值不代表全站审计通过。三种视口无横向溢出，320×568 的设置保存按钮仍可见；减少动态效果模式把图标过渡缩至近零。

按未公开的本地设计手册中的清晰聚焦原则，顶栏移除了没有实际状态来源的 `xx` 徽章。1280×800、390×844、320×568 下均确认设置入口与时间可见、无横向溢出；顶栏设置按钮仍可打开设置窗口。桌面截图已更新，但不随公开源码发布。
