# 拟物界面实现规格

初始方案：2026-09-18。对象：`D:\YJ-Desktop` 的 TypeScript/Electron 本地桌面。目标是在全屏电脑内，让应用入口和媒体播放器像可操作的物件，同时保留本地文件浏览、播放、设置与转录入口。当前视觉以[视觉系统](../specs/visual-system.md)为准；五枚素材档案图标的后续修订与验收见[媒体归档桌面](media-archive-desktop.md)。

## 三种方案的取舍

| 方案 | 优点 | 代价 | 结论 |
| --- | --- | --- | --- |
| 全局软阴影 Neumorphism | 容易统一浅色面板 | 不能解释唱盘、按键、相纸的结构 | 不作为主风格 |
| 每个窗口完整复刻复古硬件 | 物件辨识度强 | 内容空间、窄屏和维护成本高 | 仅在媒体设备中使用 |
| 统一桌面壳 + 各媒体独立机件 | 窗口操作一致，设备有个性 | 需要精确处理材质与状态 | 本轮采用 |

## 组件规则

- **桌面**：固定冷钢蓝灰背景承载五枚透明铝制素材档案 SVG（录音、照片、视频、音乐、通用文件夹）与 Dock；通用文件夹打开 Finder，Finder 展示用户路径里的现有子文件夹。
- **窗口**：macOS 式红、黄、绿控制点分别表示关闭、最小化、放大/还原。窗框、标题栏与内容盘分层。
- **媒体**：音乐为唱盘，画廊为相纸/看片台，视频为显示器，录音入口保持磁带/回放语义。实际播放状态取自媒体元素。
- **旋钮**：视觉刻度与音量数值对应；原生 range 保留键盘与无障碍名称；减少动态效果时不依赖旋转表达播放状态。
- **文字**：长文件名、路径、转录稿与纪要保留平整阅读面；实体纹理不得压过内容。
- **性能**：CSS 绘制静态材料，动效只改变 transform/opacity；当前版本隐藏旧 Three.js 背景，媒体循环动效随真实播放状态启动或停止。

## 验收

1. 1280×800 与 390×844 下，桌面图标、Dock、窗口和五个播放器按键不裁切；文件名可读。
2. 一首真实本地音频可播放、暂停、跳转、调音量；唱盘与真实状态同步；切歌会停止旧音频。
3. 语言切换后新增播放器控件的无障碍名称同步改变；键盘可调音量和进度。
4. Finder 能读取设置路径，图片、视频、录音入口保持可用。
5. `npm run lint`、`npm run check`、`npm test`、`npm run build` 通过；完成桌面与窄屏前端 UI/UX 验收。
6. 前端确认后再重新生成 Windows 包，并从根目录验证启动；macOS/Linux 在对应系统单独验证。
