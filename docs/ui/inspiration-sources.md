## 具体使用边界

| 来源 | 用户指定的主要信号 | 本项目使用与限制 |
| --- | --- | --- |
| [Inspora](https://www.inspora.design/) | Web、Branding、Product、Motion 跨领域案例 | 用于物件轮廓与交互质感；不从聚合页推定原始素材授权 |
| [Awwwards](https://www.awwwards.com/) | 高完成度网页 | 用来校准视觉完成度；性能和可访问性另测 |
| [Godly Design](https://godly.design/) | 网站、应用、品牌组件 | 建 moodboard；不整套复制 |
| [Landing Love](https://www.landing.love/) | 页面视频与技术筛选 | 看转场节奏；落地需测减少动态效果 |
| [Lapa Ninja](https://www.lapa.ninja/) | Landing Page 全页截图 | 拆页面结构；关键判断回当前官网核验 |
| [Mobbin](https://mobbin.com/) | Web 与移动产品流程 | 查设置、搜索和媒体流程；不以单屏代替全流程 |
| [Refero Styles](https://styles.refero.design/) | 真实网站设计系统方向 | 取色彩与间距线索；适配本项目品牌和对比度 |
| [MotionSites AI](https://motionsites.ai/) | 动态站预览与 Prompt | 用于方向探索；不作为外部优秀网站证据 |
| [21st.dev](https://21st.dev/) | React 组件与模板 | 有适配需求时才试最小 PoC，并查依赖与授权 |
| [React Bits](https://reactbits.dev/) | 动效组件 | 一页只保留一个主效果，测移动端与性能 |
| [Aceternity UI](https://ui.aceternity.com/) | 强视觉组件 | 避免光效盖过文件内容 |
| [Magic UI](https://magicui.design/) | 产品动效组件 | 核对框架版本，移除闲置依赖 |
| [Motion Primitives](https://motion-primitives.com/) | 小粒度动效 | 只用于控件细节，不替代设计系统 |
| [GSAP Showcase](https://gsap.com/showcase/) | 时间线与滚动案例 | 看结果后回官方文档和最小 PoC 验证 |
| [Codrops](https://tympanus.net/codrops/) | 创意前端实验与源码 | 作为学习材料；生产性能和兼容性单独验证 |

## TASTE 门槛

- 每次记录具体参考对象：布局、动效、色彩、流程或组件；不只写“高级感”。
- 同一页面只设一个视觉主角；动效服务阅读和状态反馈。
- 外部代码先做最小 PoC，再检查许可证、依赖、移动端、性能和可访问性。
- 找不到原始页面或实现证据时写“未找到”；不以聚合页摘要替代来源。
