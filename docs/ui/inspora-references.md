## 本轮实现规格

1. **壳体**：桌面是浅色金属工作台；音乐窗口是深色设备。边框、按钮座、唱盘和控制件各有独立厚度与反光。
2. **旋钮**：保留刻度、指针和高光；滑杆值决定旋转角度与 `audio.volume`。悬停仅暗示可操作，按下才产生反馈。
3. **运动**：唱盘由播放事件控制；窗口位移动画短于 200 ms；不对全屏背景持续做昂贵模糊。
4. **证据边界**：如需一比一比对上述案例的具体画面，应先取得可查看的截图或视频；当前实现只依据已核验正文与用户的播放器图片。
