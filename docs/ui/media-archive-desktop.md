# 媒体归档桌面：工业设备拟物图标

> 这是上一版 SVG 文件夹桌面的验收记录。当前首页已改为[Three.js 3D 媒体陈列台](object-archive-3d.md)；本文截图用于比较设计迭代，不代表最新界面。

日期：2026-09-18。用户本次指定的范围是录音、照片、视频、音乐四类素材，加一个通用文件夹。参考图只提供冷铝材质、实体结构、三分之四视角和黑色展示背景；没有复用密码键盘的形状或文字。

## 设计与行为

- 五枚图标共用同一款铝制档案夹外壳、左上凸起标签、琥珀色指示灯与左上主光源。正面分别以麦克风/波形、相片、胶片/播放键、唱片/唱臂识别四类素材；空白款是通用文件夹。
- 图标改为透明背景的自包含 SVG，借渐变、细线倒角和凹槽表达铝材结构；桌面以冷钢蓝灰渐层承托图标，不再依赖黑底遮掩位图边缘。顶栏、Finder 窗口继续用浅金属，与桌面形成明确的物件层次；Dock 是深色凹槽。
- 照片、视频、音乐、录音图标仍打开原有入口；通用文件夹打开 Finder。设置从顶栏和 Dock 进入，不再占桌面的一枚图标。
- Dock 中的录音应用按 macOS 名称显示为“语音备忘录 / Voice Memos”；桌面上的“录音素材 / Recordings”仍表示素材分类。名称调整不改变现有档案回放功能，也不表示已新增录制能力。
- Finder 中的普通文件夹也使用同一空白款图标。图标资源目录不会混进用户的媒体根目录列表。

前端细化版增加了 SVG 正面的低对比拉丝线与下沿倒角；桌面底色进一步调整为与铝制图标同色系的冷钢蓝灰，左上侧有克制的漫反射高光，右下自然压暗。打开中的素材图标有内凹选中态，关闭窗口后自动消除；Dock 的每个入口有独立凹位和琥珀色运行指示。Finder 的侧栏选中边线、搜索焦点和文件卡片悬停反馈沿用同一金属与琥珀规则，没有改动素材路径或打开方式。

## 本地资源与边界

五个独立 SVG 位于 `assets/media-archive/`，可通过 `npm run icons` 从 `scripts/generate-media-icons.mjs` 重建。每个文件都有透明背景，不含嵌入位图；本地服务按 `image/svg+xml` 只读提供，打包配置仅纳入 SVG。早期 PNG 留作设计参考，不再由界面引用。这轮已更新源代码与 `dist` 开发产物，没有重新生成根目录 EXE；Windows 打包和 macOS 实机启动均未在本轮验证。

本地预览使用 `npm run preview`：它先重建前后端，再启动 `http://127.0.0.1:8766/`，避免 HTML、服务端与旧 `dist/app.js` 混用。`?preview=metal5` 只是旧链接中的查询参数，不选择或锁定视觉版本。
