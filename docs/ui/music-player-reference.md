# 音乐播放器：用户给定的拟物参考

研究日期：2026-09-17。原始图片：[2020 年拟物界面图片](https://image.woshipm.com/wp-files/2020/02/fnN9v5fLlAKH3B6uzE0t.jpeg)。图片是视觉参考，未取得可复用素材授权，因此不纳入公开源码；产品界面用 CSS 绘制自己的设备。

## 原始画面记录

图中是浅色与深色两台音乐设备并排的设计稿。每台设备上方有唱片封面架，中部是明显的圆形黑胶唱盘，下方依次是曲目信息、进度滑轨和五枚实体控制键。盘面周围有指示灯与唱臂/拨杆。深色设备的外壳、内凹面板、金属件和按钮有不同的反光方式。

## WhyJ 分析与落地

| 可见结构 | 本项目实现 | 行为约束 |
| --- | --- | --- |
| 封面架 | 前后曲目封套与当前封套 | 只显示本地文件名，不臆造专辑封面 |
| 黑胶唱盘 | CSS 绘制的槽纹、唱片标与唱臂 | 仅在原生 `<audio>` 真正播放时旋转 |
| 指示灯、音量旋钮 | 琥珀灯与有刻度的实体旋钮 | 旋钮连到 `audio.volume`，键盘仍能调整 |
| 进度滑轨与五枚按键 | 时间、seek、上一首、后退、播放、前进、下一首 | 从 `HTMLAudioElement` 事件更新，不用演示时钟 |
| 深浅两种设备 | 当前产品选择深色音乐机身，与浅色金属桌面形成材质区分 | 保持一个视觉主角；不增加壁纸切换 |

可访问名称用 `i18next` 中英文资源管理。减少动态效果时停止唱片旋转，播放状态仍用按钮文字和时间表示。曲目缺失或格式失败时显示真实错误状态。
