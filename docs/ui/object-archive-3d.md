# 3D 媒体陈列台

历史验收快照：2026-09-18。下文“本轮/当前包”仅指当时的 YJ Desktop 阶段；现产品名为 YJ-Pocket-Desktop，1.2.0 性能与打包状态见[轻量索引方案](../specs/search-index-architecture.md)和[分发规格](../specs/electron-distribution.md)。用户指出五枚图标只是复用文件夹外形，希望改成基于 Three.js 的 3D 主界面，而不是传统桌面。这一版将首页改为可交互的物件陈列空间；五件物件立在可升降的同一张桌上，底部保留一体式 deck。现有媒体路径、Finder、预览和设置逻辑沿用。

## 物件与入口

| 素材 | 3D 物件 | 操作 |
| --- | --- | --- |
| 照片 | 带镜头、取景器和弹出相纸的相机 | 进入照片素材 |
| 视频 | 双卷盘摄影机与前置镜头 | 进入视频素材 |
| 音乐 | 带黑胶、唱臂和翻盖的唱机 | 进入音乐素材 |
| 录音 | 带拾音栅格、波形窗和录音键的手持录音机 | 打开语音备忘录档案 |
| 文件 | 三抽屉金属档案柜与露出的纸张 | 打开 Finder |

五件物件由 `src/client/archive/objects.ts` 中的 Three.js 几何构成，不是 PNG、SVG 贴在平面上。`src/client/archive/scene.ts` 负责光照、展座、响应式布局、射线点击、悬停和窄屏扫动；桌面是一块连续台板，下方有三组伸缩支撑。deck 上的升降键以 4 cm 为一步，在 72–112 cm 之间调节，台板、展座与五件物件一起移动。底部另一组五枚实体按键复用原有入口，也提供键盘和 WebGL 不可用时的后备操作。旧 SVG 文件夹仍用于 Finder 内部缩略图，不再作为首页五个入口。

## 视觉与性能

- 参考用户给出的金属密码设备与银色档案柜：全局统一中性银色拉丝金属、倒角、深色内凹显示仓、紧固螺丝和少量琥珀指示灯。背景、地面、升降桌、顶栏、标题仓、五件展品、展座、底部 deck、Finder 和设置窗口使用同一材质语言，不用蓝色。五件物体的主体形状仍不同。参考图中的棋盘格是透明底提示，不是桌面背景。
- Deck 是一体机身，不是五张分离卡片；五枚宽按键占满内凹键槽，有悬停、按下和当前分类状态。
- 大屏五件并列；窄屏聚焦当前物件，左右露出相邻物件，可点下方分类或在画布上左右扫动。
- `prefers-reduced-motion` 使用静态构图，升降直接到位；页面失焦时停止连续渲染。WebGL 初始化失败时保留文字入口。
- Finder 使用重新生成的银灰 SVG；用户自己的照片和视频内容保持原色，变成银色的是承载媒体的设备和界面。录音入口嵌入的是独立页面，当前在 YJ Desktop 的嵌入层去色以保持统一，未改动独立项目源码。
- 旧 Dock 在首页隐藏；窗口、文件服务和现有素材数据路径没有重写。根目录 EXE 未重新打包，Windows 打包与 macOS 实机仍未验证。

## 验收

历史验收截图覆盖 1280×720 银色升降桌、390×844 聚焦式陈列和银色 Finder 窗口；图片留在本地资料中，不随公开源码发布。

`npm run lint`、`npm run check`、`npm test`（3 项）与 `npm run build` 均通过。浏览器中确认 WebGL 场景已启动，直接点击相机与唱机几何体能打开对应素材；金属 deck 的音乐键也能打开音乐素材。升降键实测从 84 cm 到 88 cm。1280×720 与 390×844 已目视检查；320×568 的文档宽度等于视口宽度、五个 deck 按键可见。浏览器控制台错误和警告均为 0。截图使用本机已保存的英文界面设置。

本地预览：`npm run preview` 后打开 `http://127.0.0.1:8766/`。`?preview=atelier3` 仅是查询参数，不选择视觉版本。页面源文件和 `dist` 均需同步构建。
