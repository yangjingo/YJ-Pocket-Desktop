## WhyJ 分析

Smartisan 的启发在于**先确定物件，再确定交互**。相机图标需要镜头、机身与快门层级；唱片图标需要唱盘、中心标与播放旋转；便签需要纸张与撕取/编辑关系。统一布局不要求每个物件具有相同颜色，但要求它们共享尺度、光源和间距。

对 YJ-Pocket-Desktop 的对应关系：

| Smartisan 启发 | YJ-Pocket-Desktop 具体应用 | 验证方式 |
| --- | --- | --- |
| 真实物件的可辨认轮廓 | 画廊为相机/相纸，音乐为唱盘，录音为磁带机，视频为显示器 | 隐去文字后仍能辨认入口 |
| 材质和光影有层级 | 金属窗口、相纸边框、黑色唱盘、实体按键分别使用自己的材质 | 同一光源，材质差异清楚 |
| 布局统一而图标不趋同 | 应用入口同尺度、同基线，内部物件可以不同形 | 1280px 与 390px 视口均不拥挤 |
| 动作延续物理隐喻 | 音频播放才旋转唱片；按钮按下产生压入；进度与真实 `audio.currentTime` 同步 | 媒体事件和界面状态一致 |

## 边界

- 不把 Smartisan 手机的九宫格直接搬到电脑桌面；桌面仍遵循 macOS 式菜单栏、窗口和 Dock 的操作方式。
- 不把高光、纹理和阴影当作拟物的充分条件。每个主要造型都要有可解释的物件和用途。
- [官方 R1 系统页面](https://www.smartisan.com/r1/os)属于较晚时期版本，不能用来证明 2014 年 T1 的逐像素外观。
